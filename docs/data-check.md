Файл для проверки по книге. Данные собраны скриптом `tools/build_data.py` из текста учебника (`uchebnik_maunsa_unicode.txt`) и сверены с изображениями страниц PDF.

## Итоги

- Словарь (с. 438–461): **1133 статьи**. Буквы-заголовки (ἄλφα, βῆτα и т. д.) словами не считаются.
- Все 24 страницы словаря сверены целиком: каждая статья в данных сравнена со строкой на изображении страницы (200 точек на дюйм).

### Сбои извлечения текста, исправленные разбором
- Переносы слов внутри строки убраны («ἐμαρτύ-ρησα» → ἐμαρτύρησα), дефис внутри кода MBG сохранён (n-3f[1a]).
- Пропущенные запятые в заголовках восстановлены: «γραφή –ῆς, ἡ» → «γραφή, –ῆς, ἡ», «ἀγαθός, –ή –όν» → «ἀγαθός, –ή, –όν».
- Пробелы внутри греческих форм от выключки строк убраны («δε δόξασ μαι» → δεδόξασμαι).
- Пробел в больших числах убран («5 597» → 5597).
- Статьи, у которых в книге пропущен знак ◆, отделены от предыдущей: ἐκεῖ, καιρός, κἀκεῖ, ποῦ.

## Как пересобрать данные
```
python3 tools/build_data.py ../greek-materials/uchebnik_maunsa_unicode.txt
```
Номера слов и глаголов берутся из уже существующих `dictionary.js` и `parts.js`, поэтому при пересборке не меняются. Если исправление меняет заголовок статьи (поле `g`), скрипт остановится: тогда номер нужно перенести вручную.
