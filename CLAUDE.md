# Греческий курс: заметки для Claude

Веб-приложение для изучения библейского греческого по учебнику и рабочей тетради У. Д. Маунса. Владелец: Григорий (GitHub: Grisha-Kr). Пользователи: он, позже близкие и студенты, регистрация по приглашению. Адрес: `https://greek.grishaweb.ru`.

Устройство повторяет «Молитвенный дневник» (репозиторий Grisha-Kr/molitva). Описание сервера, домена и DNS лежит у владельца в файле «Контекст сервер и зачётка.md» и в `docs/context.md` репозитория Grisha-Kr/zachetka. При изменениях в инфраструктуре напоминать владельцу их обновить.

Работа идёт этапами. Этап 1 (сделан, метка `etap-1`): каркас, план на день, алфавит, слова лексического минимума, словарь, курс по главам, прогресс. Правки 1.1 (сделаны): фото профиля с обрезкой по кругу, неделя в «Прогрессе» с понедельника, календарь занятий (месяц и год). Дальше: полный словарь учебника (около 1130 слов), основные формы глаголов, таблицы окончаний, морфологический разбор по MorphGNT, чтение стихов из рабочей тетради. Перенос прогресса из старого приложения не делался.

## Источники
- Grisha-Kr/greek-alphabet: старое приложение «Греческий алфавит». Только читать. Оттуда `data.js` (→ `pb_public/data/letters.js`), `words.js` (→ `pb_public/data/words.js`), шрифт Gentium Plus, логика карточек, теста, повторения и словаря. Файлы данных скопированы побайтно.
- Grisha-Kr/greek-materials (закрытый): PDF учебника и рабочей тетради и их текст в Юникоде (`uchebnik_maunsa_unicode.txt`, `tetrad_maunsa_unicode.txt`, разметка `=== [стр. N] ===`). Ни PDF, ни текст книг в этот открытый репозиторий не копировать: только короткие выдержки (названия, слова, формы). Оглавление учебника на с. 469–471.

## Общение с владельцем
- Только на русском. Английские слова и названия сопровождать переводом в скобках.
- Владелец не программист: объяснять простыми словами, команды давать готовыми к вставке, по одной задаче за раз, говорить, где выполнять (Mac или сервер).
- Без длинных тире, без эмодзи, без конструкций «не X, а Y», без пафоса и лишних повторов.
- Пароли нигде в коде и инструкциях не писать.

## Стек
- **PocketBase 0.40.3**, версия в `deploy/install.sh` (`PB_VERSION`). До 1.0: перед обновлением читать заметки к выпуску.
- Фронтенд без сборки: `pb_public/index.html`, `app.css`, `app.js` (обычный JS, одна IIFE). Данные учебника отдельными скриптами в `pb_public/data/` (глобальные `LETTERS`, `WORDS`, `SPECIAL`, `PARTS`, `CHAPTERS`), подключаются до `app.js`. Библиотека `pb_public/vendor/pocketbase.umd.js` (JS SDK 0.28.1). Внешних CDN нет намеренно.
- Шрифты в `pb_public/fonts/`: Gentium Plus 400/700 (заголовки и весь греческий, `--f-head`, класс `.gr`) и Golos Text 400/500/600 (интерфейс, `--f-body`, подмножества cyrillic и latin с `unicode-range`). Греческих букв в Golos нет, поэтому в `--f-body` после Golos стоит Gentium Plus. Лицензии OFL рядом.
- PWA: `manifest.webmanifest`, `sw.js` (кэширует оболочку, данные учебника и шрифты; `/api/` не трогает). При изменении `app.js`/`app.css` увеличивать `?v=` в `index.html` и `VERSION`/`SHELL` в `sw.js`; при изменении файлов `data/` тоже увеличивать их `?v=` в обоих местах. По `?v=` у `app.js`/`app.css` открытое приложение узнаёт о новой версии и показывает плашку «Вышло обновление».
- Значки в `pb_public/icons/` (из старого приложения, α на кирпичном фоне, ссылки с `?v=1`). Подпись под значком «Греческий» (`short_name`, `apple-mobile-web-app-title`), полное имя «Греческий курс».

Тёмная: #1C1916, #26221E/#3A342E без тени, #EEE6D8, #A3978A, #3A342E, #D9896F (текст #1C1916), #3A2A23, #8FC08A, #211D19. Цвета вне задания: `--bad` (ошибка, трудное) из старого приложения, `--learn` (в изучении на «Прогрессе»).

## Данные (pb_migrations: 1780000000_init.js, 1781000000_v11.js)
Изменения схемы только **новой** миграцией, старую не править: на сервере она уже применена.
- `users`: role (user/admin), theme (auto/light/dark), avatar (правки 1.1: protected, jpg/png/webp/heic до 10 МБ, приложение кладёт только круг 400×400 JPEG). Роль через API не меняется (updateRule). Видит и меняет только себя, чужое фото по токену не открывается.
- `invites`: code (уникальный), note, max_uses, uses, expires, created_by, used_by. Только `role = "admin"`. created_by, uses и used_by ставит сервер.
- `word_progress`: user, n (номер слова), level (0–6, ступень интервала), due (`YYYY-MM-DD`, день следующего повторения), hard (bool). Уникальная пара (user, n). Нет записи = слово новое.
- `letter_progress`: user, n (1–24), known, hard. Уникальная пара (user, n).
- `plan_days`: user, date, tasks (JSON), done (все задания выполнены). Уникальная пара (user, date).
- Правила всех трёх: `user = @request.auth.id`, создавать только с `user` = себе, менять `user` нельзя. Удаление пользователя удаляет всё каскадом.
- Резервная копия базы в 3:00, хранится 14 (задаёт миграция). Имя приложения в настройках «Греческий курс».

### Номера слов постоянные
- `n` в `word_progress` = поле `n` в `pb_public/data/words.js`. Номера **1–320** закреплены за словами лексического минимума навсегда: их нельзя менять, переставлять и переиспользовать, иначе прогресс пользователей перепутается.
- На этапе 2 полный словарь учебника (около 1130 слов) включает эти же 320 слов с теми же номерами, новые слова получают номера с **321** и дальше. Поле `n` допускает номера до 9999.
- Если слово минимума нужно исправить (опечатка в переводе, форма), правится текст, номер остаётся.

## Логика на сервере (pb_hooks/main.pb.js)
- Первый пользователь получает `role=admin`; остальные только с действующим кодом `invite` (регистр не важен), счётчик `uses` и список `used_by` растут.
- `GET /api/greek/setup` → `{firstRun, owner, contact}`.
- `APP_URL` из окружения пишется в настройки, `BEHIND_PROXY=1` включает доверие к X-Forwarded-For.
- В обработчиках PocketBase код верхнего уровня файла недоступен: общие функции класть в `pb_hooks/lib.js` и подключать через `require(`${__hooks}/lib.js`)` внутри обработчика (как в «Молитвенном дневнике»).

## Клиент (pb_public/app.js)
- Ключи состояния `words`, `letters`, `plans` (`PBN`), индексы `WP` и `LP` (номер → запись). `plans` загружаются за последние 400 дней.
- **Сохранение через очередь** (`saveRec(key, значение ключа, изменения)`): запись сразу меняется на экране и в кэше устройства, ключ попадает в `Q` (`gk_queue_<id>` в localStorage), `flush()` отправляет на сервер. Без связи очередь ждёт события `online`, возврата на вкладку или следующего запуска. Конфликт уникальности (запись создана с другого устройства): берётся запись сервера и обновляется; у плана отметки «сделано» объединяются (`mergePlan`). Живые обновления (`subscribe`) не перетирают записи, которые ещё в очереди.
- **Без интернета**: при запуске сначала показывается кэш (`gk_cache_<id>`), потом данные с сервера. При выходе кэш и очередь удаляются (с подтверждением, если очередь не пуста).
- Экраны по адресу после `#`: `#/` сегодня, `#/task/review|new|alphabet` задание плана, `#/course`, `#/ch/N` глава, `#/abc?m=cards|quiz|table` алфавит (глава 3), `#/dict` словарь, `#/words?r=all|c:N|u:N&m=quiz` карточки и тест слов, `#/progress`, `#/profile`. Экраны с `still: true` (`VIEWS`) не перерисовываются от изменений данных, только при переходе, чтобы не сбить карточку или поиск.
- День считается по часам устройства (`todayISO`), раз в 30 секунд и при возврате на вкладку проверяется смена дня.
- Фото профиля (правки 1.1, как в «Молитвенном дневнике»): окно `#crop` (`cropPhoto`), фото уменьшается до 1600 точек, двигается пальцем и мышью, увеличивается двумя пальцами, колесом и ползунком от 1 до 4, в круге не остаётся пустоты; «Готово» сохраняет квадрат 400×400 JPEG в `users.avatar`. В окне «Выбрать другое фото» и «Удалить фото» (с подтверждением). HEIC, который браузер не открывает, не принимается (просьба выбрать JPG или PNG). Загруженное фото хранится в памяти и в `gk_avatar_<id>` (data:), поэтому кружок с фото виден и без интернета; при выходе удаляется. Кружок в шапке и в профиле (`avatarInner`, атрибут `data-av`), без фото первая буква имени.
- Календарь занятий (`#cal`, `openCalendar`): открывается нажатием на карточку «План выполнен». Только просмотр. Состояние дня `dayState`: `full` план выполнен (есть задания и все сделаны), `half` сделано хотя бы одно задание, иначе пусто. Вид «Месяц» (сетка с понедельника, стрелки) и «Год» (12 маленьких месяцев, нажатие открывает месяц). Сверху «В этом месяце: занимались N дней, из них весь план M». Закрывается крестиком, по фону, Esc и жестом «назад» (`history.pushState`). Класс `.part` занят карточками частей курса, поэтому неполный день `half`.
- Неделя в карточке «План выполнен»: с понедельника по воскресенье текущей недели (`weekStart`), сегодня обведено, будущие дни бледные.

### План на день
- Составляется (`buildPlan`) при первом открытии дня и хранится в `plan_days`, в течение дня состав не меняется. Задания в порядке `TASK_ORDER`: `review` (слова с `due <= сегодня`, есть только если их больше нуля, `count`), `new` (следующие 10 слов без записи по порядку номеров, `words` = их номера), `alphabet` (буквы не «знаю» или трудные, есть пока такие есть).
- Колода задания (`taskDeck`) считается по текущему прогрессу: `review` все слова со сроком, `new` слова плана без записи или со сроком сегодня, `alphabet` трудные и невыученные буквы. Задание отмечается сделанным, когда колода пройдена до конца (`markTask`), или само, если колода стала пустой (`checkPlan`).
- «Дни подряд» (`streak`): дни с `done = true` подряд, считая от сегодня или, если сегодня не выполнен, от вчера.

### Слова, буквы, главы
- Повторение перенесено без изменений: интервалы `INT` 0, 1, 3, 7, 14, 30, 60 дней; «Знаю» новому или ошибочному в этой сессии слову даёт ступень 1 на завтра, слову со сроком следующую ступень; «Повторить» = ступень 0, срок сегодня, трудное, слово возвращается через три карточки. Ошибка в тесте = то же. Набор «Повторение» вне плана: слова со сроком из диапазона плюс 10 новых. Тест 20 вопросов, 4 варианта, неверные варианты из той же части речи (`distractors`).
- Состояния слова (`wState`): впереди (нет записи), трудное (`hard`), уверенно (ступень от 4, интервал от двух недель), в изучении. «Выучено» в курсе и на карточке главы (`isLearned`): хотя бы раз «знаю» (ступень от 1) и сейчас не трудное.
- Глава пройдена (`chapterDone`): со словами, когда все её слова начаты; глава 3, когда все 24 буквы «знаю»; главы 1–2 вместе с главой 3; главы без слов (5, 15, 26, 35) вместе с предыдущей. Текущая глава: первая непройденная глава с заданиями.
- Поиск в словаре (`norm`): без ударений, придыханий, регистра, с σ = ς и е = ё.

- Сервер: AdminVPS, Ubuntu 24.04, IP 168.113.170.172. Рядом «Зачётка» (порт 8090) и «Молитвенный дневник» (8091).

Локально: `./pocketbase serve --http 127.0.0.1:8092 --dir /tmp/greektest --publicDir pb_public --hooksDir pb_hooks --migrationsDir pb_migrations`, затем в браузере (Playwright) на ширине 390px и 1280px, в светлой и тёмной теме: регистрация первого пользователя, приглашение, второй пользователь видит только свой прогресс (и прямыми запросами к API), план на сегодня (новые слова, повторение, алфавит), отметка заданий, следующий день (`page.clock.setFixedTime`): план пересчитан, слова со сроком в повторении; карточки, тест, словарь с поиском без ударений, курс по главам, тема после перезагрузки, работа без интернета (`context.setOffline`) и отправка очереди после возврата связи. Миграции проверять и на чистой базе, и на копии с данными прошлого этапа.
