# Греческий курс

Веб-приложение для изучения библейского греческого по учебнику и рабочей тетради У. Д. Маунса «Основы библейского греческого языка». Курс идёт по учебнику глава за главой: вы читаете текущую главу, а приложение помогает заучить то, что велит автор, в том порядке, в каком идёт книга. Каждый день открываете «План на сегодня»: повторение слов, у которых подошёл срок, новые слова глав до текущей, основные формы глаголов тех времён, которые учебник уже ввёл, и алфавит, пока он не выучен. Есть курс по главам, полный словарь учебника (1133 статьи, все слова, которые встречаются в Новом Завете 10 раз и больше), основные формы 90 глаголов, карточки, тесты и страница прогресса. Работает в браузере на телефоне и компьютере, ставится на экран как приложение и открывается без интернета.

Адрес: **https://greek.grishaweb.ru**

Устроено так же, как «Молитвенный дневник»: одна программа [PocketBase](https://pocketbase.io) (база данных, вход, панель администратора) плюс страницы приложения из папки `pb_public`.

```
pb_public/       интерфейс приложения (HTML, CSS, JS, шрифты, значки)
pb_public/data/  буквы, слова, словарь, основные формы и главы учебника (в базу не кладутся)
pb_migrations/   структура базы и правила доступа
pb_hooks/        приглашения и первый администратор
deploy/          установка и обновление на сервере
tools/           сборка словаря и основных форм из текста учебника
docs/            карта курса по главам (course-map.md) и итоги сверки данных с книгой (data-check.md)
```

Этап 1 (сделан): каркас, план на день, алфавит, слова, словарь, курс по главам, прогресс. Правки 1.1 (сделаны): фото профиля, неделя с понедельника и календарь занятий. Этап 2 (сделан): полный словарь учебника, наборы слов по частоте, основные формы глаголов, доля текста Нового Завета. Правки 2.1 (сделаны): курс по главам учебника с кнопкой «Глава пройдена», карта курса, основные формы по главам. Дальше: таблицы окончаний, морфологический разбор, чтение стихов из рабочей тетради.

## Установка на сервер

Приложение ставится на тот же сервер рядом с «Зачёткой» и «Молитвенным дневником». Общие настройки Caddy (файл `/etc/caddy/Caddyfile`) установка не меняет, другие сайты продолжают работать как раньше.

### Что нужно заранее

В Beget, в DNS домена `grishaweb.ru`, добавлена подзона `greek` с A-записью `168.113.170.172`. После добавления подождите 15–60 минут.

### Установка одной командой

Подключитесь к серверу (`ssh root@168.113.170.172`) и выполните:

```
curl -fsSL https://raw.githubusercontent.com/Grisha-Kr/greek-course/main/deploy/install.sh | bash -s -- greek.grishaweb.ru me@grishakr.ru "Григорий Кривобок"
```

Скрипт сам:
- проверит, что в общем файле Caddy есть строка `import /etc/caddy/sites/*.caddy` (если её нет, остановится и объяснит, что делать);
- проверит, что адрес указывает на сервер;
- скачает код и PocketBase 0.40.3 в `/opt/greek`;
- включит автозапуск (служба `greek`, порт `127.0.0.1:8092`);
- положит файл сайта `/etc/caddy/sites/greek.caddy` (только TLS 1.2), проверит настройки и перезагрузит Caddy;
- создаст вход в панель администратора и покажет пароль. Он же сохранится в `/opt/greek/superuser.txt`.

### Первый вход

**Сразу после установки** откройте `https://greek.grishaweb.ru` и создайте аккаунт. Первый зарегистрированный пользователь становится администратором; остальные смогут зарегистрироваться только по вашему приглашению.

## Приглашения

«Профиль» (кружок с буквой в правом верхнем углу) → «Приглашения». Укажите, для кого приглашение и сколько человек может по нему зарегистрироваться, нажмите «Создать и скопировать ссылку». Ссылку можно переслать в мессенджере: человек откроет её, и код подставится сам.

## Установка на телефон и компьютер

- **iPhone** (Safari): откройте сайт → «Поделиться» → «На экран „Домой“».
- **Android** (Chrome): меню из трёх точек → «Установить приложение» или «Добавить на главный экран».
- **Компьютер** (Chrome, Edge, Яндекс Браузер): значок установки в адресной строке справа.

После первого открытия приложение работает и без интернета: ответы сохраняются на устройстве и отправляются на сервер, когда связь вернётся.

## Обновление

Когда в репозитории появилась новая версия, подключитесь к серверу и выполните:

```
bash /opt/greek/src/deploy/update.sh
```

Скрипт останавливает приложение, сохраняет копию базы в `/opt/greek/pb_data/backups`, загружает новый код и запускает приложение. В конце он пишет «Готово: приложение обновлено и работает». При ошибке приложение запускается снова на старой версии.

Чтобы обновить сам PocketBase, поменяйте `PB_VERSION` в `deploy/install.sh` и запустите установку ещё раз с теми же параметрами. Перед этим прочитайте заметки к выпуску: до версии 1.0 в PocketBase бывают несовместимые изменения.

## Где настройки

Файл `/opt/greek/greek.env`:
- `APP_URL`: адрес приложения (нужен для писем восстановления пароля);
- `OWNER_NAME`, `CONTACT_EMAIL`: данные оператора для политики конфиденциальности;
- `BEHIND_PROXY=1`: приложение стоит за Caddy.

После правки выполните `systemctl restart greek`.

Панель администратора PocketBase: `https://greek.grishaweb.ru/_/` (почта и пароль в `/opt/greek/superuser.txt`).

## Курс по главам

Сверху на «Сегодня» карточка текущей главы: номер, название, страницы учебника и рабочей тетради, список «Заучить в этой главе» (нажмите, чтобы раскрыть) и кнопка «Глава пройдена». Прочитали главу и сделали упражнения: нажмите кнопку, приложение спросит подтверждение и сделает текущей следующую главу. Само оно главу не закрывает.

Если слова главы ещё не все начаты, они никуда не пропадут: придут в новых словах раньше слов следующей главы. Вернуться к пройденной главе можно на экране «Курс»: откройте главу и нажмите «Сделать текущей». Прогресс при этом не стирается.

На экране главы: страницы, что заучить (со страницами книги), что автор считает второстепенным, слова главы (карточки и тест) и основные формы, которые открывает глава. Главы впереди можно смотреть и учить карточками, в план на день они придут в свой черёд. Подробная карта курса со ссылками на страницы: `docs/course-map.md`.

## Как устроен план на день

План составляется при первом открытии дня по часам устройства:
- **Слова к повторению**: слова из любых глав, у которых подошёл срок.
- **Новые слова**: 10 слов лексического минимума глав до текущей, по порядку учебника, плюс до 10 слов, которые вы сами добавили из словаря. Если слова пройденных глав все начаты, задания нет, а в карточке главы подсказка нажать «Глава пройдена». После главы 36 новые слова идут из всего словаря, от частых к редким.
- **Основные формы**: до 5 новых форм для заучивания в день и повторение тех, у кого подошёл срок. Появляется с главы 19. Задание можно выключить в профиле.
- **Алфавит**: с главы 3, пока все 24 буквы не отмечены «знаю».

Когда вы нажимаете «Глава пройдена», ещё не начатые задания пересобираются для новой главы. Если новые слова на сегодня уже начаты или сделаны, слова новой главы придут завтра; начать их сразу можно на экране главы.

Задание считается сделанным, когда пройдено до конца. «Дни подряд» на странице «Прогресс» считают дни, когда выполнен весь план.

На странице «Прогресс» неделя идёт с понедельника по воскресенье. Нажмите на карточку «План выполнен», чтобы открыть календарь занятий: месяц или весь год. Закрашенный день: план выполнен полностью, светлый: сделана часть заданий.

## Фото профиля

«Профиль» → «Поставить фото». Фото можно сдвинуть пальцем или мышью и увеличить, в кружок попадёт то, что внутри круга. Форматы JPG, PNG, WEBP и HEIC, до 10 МБ. На сервере хранится только маленький круглый вариант, его видите только вы. Там же фото можно заменить («Выбрать другое фото») или удалить.


## Повторение

«Знаю» отодвигает слово на 1, 3, 7, 14, 30 и 60 дней, «Повторить» возвращает его через три карточки и сбрасывает интервал, ошибка в тесте тоже сбрасывает. У основных форм то же самое.

## Словарь

Вкладка «Словарь»: переключатель «Минимум (320)» и «Весь словарь», фильтры по главе, частоте в Новом Завете (500, 100, 50, 25, 10 раз и больше) и части речи, поиск по-гречески без ударений и по-русски. Нажмите на слово, чтобы открыть его статью: значение, частотность, глава лексического минимума, код MBG, временные формы. Слово не из минимума можно «Добавить в изучение», тогда оно придёт в новых словах плана. Так можно учить и 15 слов главы 35, которые автор советует по желанию.

Карточки и тест слов можно открыть по главам, по частоте и для «Моих добавленных» слов.

## Основные формы

Раздел открывается из «Курса» и из статьи глагола в «Словаре». 90 глаголов, которые встречаются в Новом Завете 50 раз и больше (учебник, с. 412–421). Автор велит заучивать только формы, выделенные в таблице полужирным: 51 форма у 22 глаголов. Остальные образуются по правилам (с. 413).

Формы открываются вместе с главами, где учебник вводит время: настоящее в главе 16, будущее в 19 (у λέγω, οἶδα, ἔρχομαι в 20), имперфект ἤμην в 21, второй аорист в 22, первый в 23, аорист страдательного залога в 24, перфект в 25. Глагол входит в раздел вместе с главой, где он есть в лексическом минимуме.

- **Карточки**: одна карточка = одна форма для заучивания. На лицевой стороне глагол, значение, корень и вопрос («Аорист действительного залога?»). На обороте ответ, ниже все открытые формы глагола: для заучивания крупно, остальные мелко с подписью «по правилу». Сноски книги свёрнуты в строку «Пояснения».
- **Тест «Какая это форма?»**: только открытые формы глаголов пройденных глав. Ошибка в форме для заучивания возвращает её карточку в повторение.
- **Таблица**: открытые времена и глаголы пройденных глав, «Показать всю таблицу книги» показывает остальное бледным.

## Доля текста Нового Завета

На странице «Прогресс»: «Вы знаете слова, которые составляют N% текста Нового Завета». Это сумма частотности выученных слов, делённая на число слов Нового Завета (138 167, по учебнику). Выученным считается слово, которое вы хотя бы раз отметили «Знаю» и которое сейчас не трудное.

## Резервные копии

- Сервер сам делает копию базы каждый день в 3:00 и хранит 14 последних. Скачать или восстановить: панель `/_/` → «Settings» (настройки) → «Backups» (резервные копии).
- Перед каждым обновлением `update.sh` кладёт копию в `/opt/greek/pb_data/backups`.

## Почта для восстановления пароля

Пока почта не настроена, кнопка «Забыли пароль?» письмо не отправит. Настройка такая же, как в «Зачётке»: панель `/_/` → «Settings» → «Mail settings» (почта), SMTP Яндекса (`smtp.yandex.ru`, порт 465) или Beget с паролем приложения.

## Если что-то не работает

```
systemctl status greek             # работает ли приложение
journalctl -u greek -n 50          # последние сообщения и ошибки
systemctl restart greek            # перезапуск
systemctl status caddy             # работает ли Caddy (https и адреса)
journalctl -u caddy -n 50          # ошибки получения сертификата
```

## Персональные данные

Приложение хранит почту, имя и прогресс пользователей на сервере в России. При регистрации пользователь даёт согласие на обработку данных, страница политики: `/privacy.html`. Каждый видит только свой прогресс, это проверяет сервер.

## Как пересобрать словарь и основные формы

Нужен закрытый репозиторий `greek-materials` рядом с этим. Из папки этого репозитория:

```
python3 tools/build_data.py ../greek-materials/uchebnik_maunsa_unicode.txt
```

Исправления после сверки с книгой лежат в `tools/dict_fixes.py` и `tools/parts_fixes.py`. Номера слов и глаголов при пересборке не меняются: на них держится прогресс.

## Разработка у себя на компьютере

```
./pocketbase serve --http 127.0.0.1:8092 --dir /tmp/greek --publicDir pb_public --hooksDir pb_hooks --migrationsDir pb_migrations
```

Приложение откроется на `http://127.0.0.1:8092`, панель на `http://127.0.0.1:8092/_/`.
